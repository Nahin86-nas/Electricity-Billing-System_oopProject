# Electricity Billing System – OOP Project

A Java-based Electricity Billing System developed as part of our **Object-Oriented Programming (OOP) course project**. The project aims to simulate a basic electricity billing management system, incorporating core OOP principles such as Encapsulation, Inheritance, Polymorphism, and Abstraction.
